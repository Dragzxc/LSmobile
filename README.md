# LS Mobile

An Android performance companion with a floating HUD overlay.

## Current functionality
- Floating overlay panel.
- Overlay permission management.
- Android APK build through GitHub Actions.

## Planned research
- Frame interpolation.
- Image upscaling and sharpening.
- Performance monitoring.

Frame generation and universal system-wide upscaling are not implemented.
Android restrictions may prevent processing frames from other applications.

## Build
GitHub Actions builds a debug APK on every push to main.
